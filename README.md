# Cloud Security System (AI + Blockchain + Quantum)

## Overview
This project is a multi-layered cloud security prototype that detects anomalous network activity and ensures secure, tamper-proof logging.

## Features
- LSTM-based anomaly detection
- Hybrid decision system (ML + rules)
- SHA3-based quantum-resistant encryption
- Blockchain-based immutable logging
- Real-time UI using Streamlit

## Tech Stack
- Python
- TensorFlow / Keras
- Streamlit
- Scikit-learn
- Joblib

## Workflow
1. Input network data
2. Preprocessing and normalization
3. AI-based anomaly detection
4. Hybrid decision logic
5. Encryption (SHA3)
6. Blockchain logging

## Demo
- Normal input → No logging
- Anomalous input → Encrypted + logged in blockchain

## Results
- Accuracy: ~79%
- Successfully detects anomalies
